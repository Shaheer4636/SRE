One thing I'd suggest is to clearly define the tools being used for each task. For example, using ADO for pipelines, Git for version control, and tools like Terraform or Ansible for infrastructure — it just helps reduce any confusion and keeps everyone aligned.

Also, for onboarding, we could create a checklist-style ramp-up — like reviewing the SOW, the questionnaire, the training plan, and any recorded meetings — so new members know exactly what to go through step by step.

Then, we should look into automating the repetitive stuff — like updating IoC scripts, keeping track of deprecated services, or even generating updated architecture diagrams. These could be done easily with CI/CD pipelines or IaC automation.

Lastly, during onboarding or the architecture review, we should integrate cost estimation tools like Infracost or the AWS Pricing Calculator to get a clear idea of infrastructure expenses up front. It’ll help avoid surprises later and make planning smoother.
